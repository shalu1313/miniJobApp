# miniJobApp
A full-stack web application that allows users to view job listings, add new jobs, and view detailed job information. Built using the MERN (MongoDB, Express, React, Node.js) stack.

## Features

- View a list of available job postings
- Add a new job listing
- View full details of individual job posts
- Responsive design using  Tailwind Css
- Backend API with Express and MongoDB

- ## Tech Stack

- **Frontend**: React, JavaScript,Tailwind CSS
- **Backend**: Node.js, Express.js
- **Database**: MongoDB (via Mongoose)
